# ☕ Kamadhatu Coffee & Resto

**Kamadhatu Coffee & Resto** is a collaborative UI/UX design project for a coffee shop and restaurant website, featuring customer-facing interfaces and an administrative dashboard.

## 📖 About the Project

This project explores how a restaurant website can provide customers with an easy and visually appealing experience for browsing menus, viewing food details, placing orders, checking promotions, making payments, and submitting reservations.

The project also includes an admin dashboard concept for managing restaurant products, promotions, orders, and reservations.

## 🎯 Project Objectives

- Create a user-friendly restaurant website experience.
- Organize food and beverage menus clearly.
- Provide intuitive ordering and reservation interfaces.
- Design an administrative interface for restaurant management.

## ✨ Main Features

### Customer Interface
- Home page and menu recommendations
- Food and beverage categories
- Product details and shopping cart
- Promotional offers
- Checkout and payment interface
- Restaurant reservation form
- Contact information and footer

### Admin Dashboard
- Admin login
- Dashboard overview
- Food and beverage management
- Product creation and editing
- Promotion management
- Order list and order details
- Reservation management
